プライバシーポリシー

アプリ：ほりほりタンクバトル（ほりタン）
制定日：2026年10月12日

AltVizn（以下「開発者」）は、スマートフォン向けゲーム「ほりほりタンクバトル」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

1. 開発者が集める情報

本アプリには会員登録はなく、氏名・メールアドレス・電話番号・住所などを入力していただくことはありません。オンライン機能を使うときに、次の情報を扱います。

情報使い道
匿名のプレイヤーID（本アプリが自動で作るもの）オンライン対戦の接続、ランキングの記録
プレイヤー名（ご自身で設定したもの）対戦相手の画面とランキングに表示
自作アイコンの図柄対戦相手の画面とランキングに表示
レート・順位・対戦結果ランキングの集計と表示
対戦中の操作内容、通信のための IP アドレスなどオンライン対戦の中継（記録として保存はしません）

プレイヤー名と自作アイコンは、ほかの利用者にも見える形で公開されます。個人を特定できる名前や画像は使わないでください。

報酬の進み具合、設定、自作アイコンなどは、お使いの端末の中に保存されます。

2. 広告について

本アプリは広告で運営しており、Unity Technologies 社の広告サービス（Unity LevelPlay、Unity Ads）を使っています。これらのサービスは、広告の表示・効果測定・不正防止のために、次のような情報を集めることがあります。

  • 広告識別子（IDFA など）や端末の識別子
  • 端末の機種・OS・言語・通信の種類などの情報
  • おおまかな位置（国や地域。IP アドレスから推定）
  • 広告の表示やタップなどの記録

iPhone では、他社のアプリやウェブサイトをまたいだ追跡（トラッキング）の許可を、最初に iOS の画面でおたずねします。許可しなくても、本アプリは同じように遊べます（その場合は、個人に合わせない広告が表示されます）。許可は iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」からいつでも変更できます。

欧州経済領域（EEA）・英国・スイスなど同意が必要な地域では、最初に本アプリの画面で同意をおたずねします。米国にお住まいの方は、「個人情報を販売・共有しない」を選べます。どちらも本アプリの「設定」→「プライバシー」からいつでも変更できます。

各社の情報の取り扱いは、次のページをご覧ください。

  • Unity Game Player and App User Privacy Policy（Unity Ads、Unity LevelPlay、Unity Gaming Services）

3. 外部サービス

オンライン対戦とランキングには、Unity Technologies 社の Unity Gaming Services（Authentication、Multiplayer、Relay、Leaderboards）を使っています。1. の情報は、これらのサービスのサーバー（日本国外を含みます）で処理されます。

4. 写真への保存

シェア機能で「画像を保存」を選んだときだけ、シェア用の画像を「写真」に保存します。写真を読み取ることはありません。

5. 情報の第三者への提供

開発者は、法令にもとづく場合を除き、2. と 3. のサービス以外の第三者に、利用者の情報を提供・販売することはありません。

6. お子さまの利用について

本アプリは13歳未満のお子さまを主な対象としたものではありません。13歳未満のお子さまの情報を意図して集めることはありません。

7. 情報の削除について

端末に保存された情報は、本アプリを削除すると消えます。ランキングのプレイヤー名・アイコン・記録の削除をご希望の場合は、下のお問い合わせ先までご連絡ください。ランキングは毎月1日にリセットされます。

8. このポリシーの変更

内容を変更する場合は、このページでお知らせします。
